# Android 1.5 后台功能对齐

在系统设置中原生编辑网站基础、首页与栏目图片、文字与排版、首页开场、3D 与动效、音乐、联系与应用；所有设置写回网站正在读取的同一数据库。

- `GET /api/v1/admin-app/status`：返回网站后台同一服务器状态计算结果，须登录。
- `GET/PATCH /settings`：仅提交编辑过的字段；支持栏目取景与逐栏目比例、校园与手记文案。结构化设置超长时拒绝整个事务，避免截断 JSON；音乐最多20首。
- `GET/PATCH /homepage-intro`：首页开场参数与节点一起保存。
- `POST/PATCH /media`：支持原图、关联视频、3D 缩略图及故事集展示开关。
- 原生时间线、联系链接、歌曲、路线节点支持新增、移除和排序；图片使用系统相册选择，音乐使用系统 MP3 文件选择器。
- 助手参数、13类台词与预设使用原有 `/pet`、`/pet/presets` 接口，完整 API Key 不回传，预设不复制 Key。
- `POST /account/recovery/code`：通过既有 Cloudflare 一次性许可或有效 token 后，向本站已配置管理员邮箱发送验证码；60秒发送间隔、10分钟有效期。
- `POST /account/recovery/complete`：提交6位验证码与12–256位新密码；最多5次错误验证码；成功后撤销全部网页/原生会话并重新登录。

上述缩写路由均以 `/api/v1/admin-app` 为前缀。两条恢复路由不要求旧登录令牌，受请求限流、人机验证、邮件码和尝试次数限制。原有连续两次密码错误后要求验证的策略保持不变。

网站后端必须同步本次 `admin_app_api.py` 和新增 `admin_account_recovery.py`。生产发布只移植增量，不用通用版覆盖私人站点路径、品牌、配置或内容。失败保存保留手机表单草稿；退出未保存的设置前会确认。

验证：Flutter analyze、36项Flutter测试（含320×640页面、设置增量保存、草稿、未知数据保留及裁剪像素），26项隔离真实HTTP功能断言，原有16项登录安全回归。尚未连接Android真机；系统相册/文件选择、覆盖安装、Cloudflare与实际邮件送达需要设备验收。

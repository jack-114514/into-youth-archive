# 安卓管理应用隐私政策

生效日期：2026-10-03。适用版本：开源通用管理 App 1.4.1+13（org.memoryarchive.admin.secure），配套自建网站 v3.3.1。

本政策说明未经改动的开源客户端和配套后端实际如何处理数据。网站由安装者自行运营；你选择的站点运营者管理其服务器、内容与第三方配置。开源项目维护者不因发布源码或 APK 而获得你的站点账号、密码、照片或数据库。

[下载与功能说明](README.md) · [网站技术与数据结构](../docs/TECHNICAL.md)。

## 1. 处理哪些数据、用于什么目的

| 数据 | 处理位置与用途 |
| --- | --- |
| 自选站点地址、可选更新清单 | 保存在手机安全存储，用于连接指定站点和检查自有更新 |
| 管理员邮箱与登录密码 | 登录时通过 HTTPS 发给所选站点；客户端不持久保存密码 |
| 访问/刷新令牌 | 手机安全存储按站点 origin 分组，用于会话和刷新；后端保存令牌摘要与有效期 |
| 手动选择的图片/视频 | 手机读取并压缩到临时文件；点击保存时上传到所选站点 |
| 内容编辑 | 标题、正文、日期、顺序、展示开关等发送至本站并保存到数据库 |
| 留言与投稿 | App 读取本站已有昵称、头像、文字、图片、状态；投稿还可包含联系邮箱，用于审核 |
| 基础设置 | 网站名称、主标题、介绍、时间线等保存到所选站点 |
| 状态与日志 | 查询内容数量、存储、API 状态、会话和操作摘要，供管理员维护 |

系统网络通信会向接收方暴露连接所需的信息，如 IP 地址、请求时间和路径。后端 HTTP 日志记录时间、来源地址和请求行；App 操作日志记录动作、资源类型/ID、请求 ID、时间，不记录完整登录密码或完整请求正文。

本项目客户端没有接入广告、行为分析、广告标识符采集或崩溃上报 SDK，也没有面向项目维护者的内置数据上报接口。

## 2. 图片、视频和公开展示

当前图片压缩显式设置 `keepExif: true`，可能保留拍摄时间、设备等原有 EXIF；定位等元数据是否保留取决于源文件与处理实现。视频保留音轨，也可能含原有元数据。压缩不等于隐私脱敏；上传前请自行检查素材、人脸、声音和定位信息。

相册原文件不会由压缩操作修改或删除。压缩失败时图片可能直接使用所选原文件。临时压缩文件保存在应用临时目录。

上传文件由自己的 VPS 保存，默认通过 `/uploads/*` URL 提供。媒体的显示开关、留言的隐藏状态只控制页面/列表展示，不为文件 URL 增加登录保护。公开内容可被访客保存、转发或缓存。

## 3. Android 权限

根据当前通用发行 APK 的合并清单：

| 权限 | 用途 / 当前行为 |
| --- | --- |
| INTERNET | 连接站点 API、加载图片、按配置检查或下载更新 |
| READ_MEDIA_IMAGES / READ_MEDIA_VIDEO | 媒体依赖声明，用于用户选择与处理图片/视频 |
| READ_MEDIA_AUDIO | 媒体依赖合并声明；当前界面没有音频库浏览或音频上传入口 |
| READ_EXTERNAL_STORAGE（最高 SDK 32）/ WRITE_EXTERNAL_STORAGE | 旧 Android 版本及媒体依赖的文件读写需求 |
| 应用内部 DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION | 内部接收器隔离，不用于读取其他应用的数据 |

运行时是否弹出权限请求取决于系统版本、系统照片选择器与压缩依赖的实现。你可以在 Android 设置中管理媒体权限；拒绝后部分选择/压缩操作可能不能完成。

当前 APK 未声明定位、联系人、摄像头或麦克风权限，当前上传入口是相册选择。没有直接拍摄、录音、读取通讯录或后台定位功能。源码禁止明文网络并关闭 Android 自动备份；这些设置不等同于所有本机文件均无法被设备管理员访问。

## 4. 数据会发给谁

| 接收方 | 何时参与 |
| --- | --- |
| 你配置的站点 / VPS 运营者 | 连接验证、登录、管理查询、内容保存与上传 |
| 内容指定的图片等 HTTPS 地址 | 加载该内容时；绝对 URL 可能指向其他域名 |
| 自选更新清单及其中的下载/发布地址 | 点击检查、下载更新或打开发布页；APK 地址可能与站点不同域 |
| 自己站点的 Cloudflare | 运营者启用代理时处理网站通信；网页账号恢复启用 Turnstile 时参与验证 |
| 自己配置的邮件服务 | 网页账号恢复发送管理员邮箱验证码时 |
| 自己配置的 DeepSeek | 网站桌宠 AI 被启用且发生对话时；后端发送聊天文本及用于角色互动的身份信息 |
| 证书机构 | Caddy 为自己的域名申请/续期 HTTPS 证书时，处理域名及证书联系邮箱 |

安卓 App 的“账号安全/忘记密码”会打开所选站点的网页；该网页所加载的 Turnstile 和邮件恢复按站点配置执行。当前原生 App 没有桌宠聊天界面，DeepSeek 属于可选的网站功能。

更新清单输入要求与所选站点同一 HTTPS origin，但更新请求可跟随服务器重定向，清单中的 APK / 发布页也可使用其他 HTTPS 地址。管理 API 请求则禁止跟随重定向。项目没有预设原作者更新地址，留空时不请求更新清单。

上述服务按你的站点配置和使用动作参与；其独立的数据处理方式由相应服务与站点运营者说明。

## 5. 存储与保护措施

- 手机通过 flutter_secure_storage 保存连接与会话，令牌按 origin 隔离；登录密码只用于当前登录流程。
- 配套后端使用随机盐和 PBKDF2-HMAC-SHA256（600,000 次迭代）存储密码摘要，会话令牌以摘要保存。
- App 使用 HTTPS，不包含账号、Cloudflare Secret、SMTP 密码或站长 AI Key；网站秘密保留在自己的后端配置/数据库。
- 真实 .env 权限为 0600，备份目录为 0700；保护效果还取决于 VPS 权限、托管环境和设备状态。
- 网站数据库、上传文件和备份没有由本项目统一进行磁盘加密；站长应自行管理服务器与备份访问权限。

App 显示的内容可能暂存在内存、组件缓存或临时目录；下载的 APK、压缩媒体也属于本机临时文件。本项目没有承诺这些文件在一次上传后立即全部清除。

## 6. 保留、退出、切换和删除

| 操作 / 数据 | 实际结果 |
| --- | --- |
| App 访问令牌 / 刷新令牌 | 默认分别有效 30 分钟 / 30 天，服务端刷新时轮换 |
| 退出登录 | 尝试通知服务端撤销当前会话，并清除本地令牌；网络失败时远程会话可能保留至到期 |
| 切换站点 | 取消旧管理请求并清除旧站点本地令牌；不保证撤销旧服务器上的会话 |
| 卸载 / 清除 App 数据 | 移除本机连接/会话等应用数据；不删除 VPS 内容或系统相册原文件 |
| 删除媒体、留言或投稿记录 | 删除相应数据库记录；不自动清除已上传文件、备份、访客保存副本或外部缓存 |
| 网站内容、设置、操作日志、备份 | 由站点运营者维护；项目没有为所有业务数据设置统一自动删除期限 |

若需删除站点数据，应联系你所选站点的运营者；拥有该 VPS 的管理员可分别处理数据库、上传文件、备份和第三方缓存，并先核对正在使用的引用。开源维护者没有权限替你删除他人或自己的自建 VPS 数据。

## 7. 你的选择

你可以不配置更新服务，不启用网站 AI 或邮箱恢复；不用这些可选服务仍可管理本站基础内容。上传由你主动选择并保存，媒体权限可在系统设置调整。

只有在你主动向项目 issue 提交问题时，GitHub 才会接收你提交的内容。反馈时请删除密码、令牌、环境文件、数据库和私人截图；应用不会自动把这些资料上传至项目 issue。

## 8. 适用范围、联系与变更

请通过**你所连接站点提供的联系方式**联系站点运营者，询问其内容、服务器、保留周期与删除安排。开源项目的技术问题可在[仓库 Issues](https://github.com/jack-114514/into-youth-archive/issues)反馈，勿提交私人数据。

Fork 或修改客户端/服务器后，运营者应按实际的数据流、权限、第三方服务和联系方式更新自己的政策；本文件不涵盖改版新增的行为。源码更新改变相关行为时，本政策同步标注日期与适用版本。

### AI 助手管理

新Key只在管理员主动保存时，通过选定站点的HTTPS提交到该站点后端；不传给作者服务器、不在App持久化、不记录日志。后端只返回Key掩码。成功保存后输入框清空，失败时保留待编辑输入。App管理页不直接访问DeepSeek。网页聊天的签名访客Cookie用于独立限流，默认30天有效；服务端保存近期请求时间和休息截止时间，不保存聊天正文。清除Cookie后会建立新会话。

### 登录页内嵌人机验证（2026-10-03）

`REQUEST_INSTALL_PACKAGES` 只用于用户主动检查更新后交给 Android 安装器。安装需要系统确认，不会静默安装。

原生密码框下的 WebView 只加载所选站点的 Cloudflare 验证页及 Cloudflare 内部框架。Cloudflare 参与检测浏览器/设备状态以验证访问者；WebView 使用正常 Cookie 与 DOM storage。密码留在原生表单，只通过 HTTPS 发送到你选择的站点 API，不进入验证 HTML、浏览器 URL、Cloudflare 或项目作者服务器。验证 URL 含随机会话 ID，不含 App 密钥；App 密钥只在内存，服务端保存摘要。服务端校验成功后许可五分钟内有效、一次使用，App 提前四分钟失效。退出、过期、切换站点或密码错误后须重新验证。连续两次密码错误后，该验证是原生密码登录的必需步骤；运营者须配置自己的 Turnstile，在要求验证时配置缺失或第三方服务失败不放行。前两次尝试不调用 Cloudflare。

### 连续错误后的验证策略（1.4.1）

服务端持久保存本站原生管理员登录计数；前两次密码尝试无需验证，连续两次错误后第三次及后续尝试须通过 Cloudflare。修改用户名、切换网络、重开或重装 App 不能重置服务端计数。正确登录清除计数；连续30分钟无新的密码尝试后计数到期。并发请求原子预留前两次机会，避免并行绕过。网站后台计数独立，原有限流保持有效。验证仍在密码框下完成，每个许可只允许一次密码尝试。自己的后端需升级到 v3.3.1；连接旧后端仍按旧规则要求每次验证。

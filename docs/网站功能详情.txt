一、安装后得到什么

1. 同一套沉浸式前台、3D 粒子树动画、照片/视频交互、网页后台和配套 API。
2. 中性的网站品牌、生成的 SVG 演示插画和独立数据库。默认演示不是原作者的真实照片。
3. 自己的网站域名、管理员邮箱和密码、上传目录、Cloudflare 与邮件配置。
4. 通用安卓管理 App：首次输入自己的 HTTPS 域名，不需要把域名写进源码。
5. Docker Compose 与 Caddy 部署；自动 HTTPS、健康检查、备份、更新和配置脚本。
6. 首次创建数据库时生成演示内容；删除演示后重启或更新不会重新填充。
7. 运行中的站点不连接原作者的网站，不共享原作者账号、数据库或云服务密钥。
8. 开源程序许可、第三方素材许可与署名继续适用。


二、前台整体外观

1. 默认以深色背景、照片卡片、艺术化大标题、细小辅助文字和动画组成。
2. 首页使用不同尺寸的栏目卡片，展示故事、3D、时间线、校园、文字、关于和留言入口。
3. 欢迎开场和首页使用独立的背景图、Logo、文字、进入效果；图片和文案可更换。
4. 桌面与手机布局响应式适配，卡片、图片与文字尺寸随窗口调整。
5. 3D 页面是全屏深色场景：中央发光粒子树，照片在周围漂浮，雪花或星点持续运动。
6. 图片点击后显示原比例大图及详情，支持全屏查看；有视频的媒体可播放视频。
7. 背景音乐与 Live2D 桌宠提供独立交互入口。
8. 实际显示由站长的图片、裁剪、颜色、文字、显示开关和场景参数共同决定。
9. 首页默认内容用于演示；部分导航和界面按钮名称来自源码，不是所有文字都属于后台配置。


三、前台栏目与访客功能

A. 欢迎开场
- 展示开场图、标题/副标题、节点文案、水印、加载状态和进入按钮。
- 支持桌面与手机不同图像和取景参数。
- 访客可设置昵称与头像；该本机身份不等同于注册账号。
- 进入后切换到首页，保留过渡动画。

B. 首页，路径 /
- 展示站点品牌、主标题、简介、栏目卡片、图片/视频与关于区域。
- 卡片可进入故事集、3D 粒子树、时间线等独立栏目。
- 栏目的首页可见性由对应设置控制。
- 页脚展示站长填写的联系方式；默认不填原作者的账号链接。

C. 故事集，路径 /stories
- 展示在故事集中启用的媒体记忆。
- 展示图片/视频、标题、附加信息、正文和日期等内容。
- 点击图片可打开原图查看，视频条目提供播放。
- 通过媒体的故事集开关与排序控制内容。

D. 3D 粒子树，路径 /memory
- 粒子构成树形，照片相框环绕，雪花/星点在背景与前景运动。
- 鼠标拖动旋转，滚轮缩放；触屏使用拖动与双指缩放。
- 悬停放大照片，点击查看详情，支持沉浸观看和返回。
- 场景、相框、粒子与雪花在图片查看过程中继续动画。
- 使用图片解码预热和有限缓存，降低点击放大时的解码阻塞。
- 详情图片按原始比例展示，正文自然展开。
- 设备 GPU、图片尺寸、粒子数量与分辨率仍会影响实际帧率。

E. 时间线，路径 /timeline
- 根据站长配置的时间线事件展示日期、标题/文字。
- 用于记录阶段、经历或事件。
- 内容在后台设置中编辑，安卓端以 JSON 编辑器修改时间线数据。

F. 校园碎片，路径 /campus
- 展示对应媒体栏目中的影像。
- 站长可换成自己的校园、生活或其他主题素材。
- 配套首页栏目图片、文案和展示设置在网页后台编辑。

G. 随手记，路径 /notes
- 展示站长设置的文字栏目内容和配套图片/文案。
- 不是独立的多人写作、Markdown 博客或文章工作流系统。

H. 关于，路径 /about
- 展示自己的简介、关于区域图片和相关文字。
- 页面展示由站长自己的设置决定。

I. 留言操场，路径 /messages
- 访客使用昵称、头像和文字留言，可附图片。
- 支持留言回复和点赞。
- 公开列表显示可见留言；站长可隐藏、恢复显示或删除。
- 访客昵称/头像不构成认证身份。

J. 投稿
- 访客提交标题、正文、图片、昵称与联系邮箱等信息。
- 进入站长审核列表。
- 站长可以接受、拒绝或删除记录。
- 接受是审核状态，不自动把投稿发布成媒体故事；公开发布由站长自行编辑。

K. 音乐
- 播放站长配置的音频列表。
- 播放/暂停、音量调节、顺序/随机/单曲循环。
- 播放与暂停采用音量渐变。
- 自动播放受浏览器策略影响，可能需要首次点击。

L. Live2D 桌宠
- 提供 Haru、Miku 示例，或使用站长自己的授权模型。
- 支持拖动、移动、鼠标跟随、交互台词与情绪表现。
- 可配置欢迎、点击、空闲等互动文字和行为参数。
- AI 对话默认关闭；站长填自己的 DeepSeek 配置后可启用。
- 模型动画不需要 AI Key，AI Key 只在后端保存。
- 第三方角色和 Cubism Core 的许可独立于本项目 MIT 许可。


四、网页后台入口与工作方式

入口：https://自己的域名/admin
账号：安装时填写的管理员邮箱和密码
模式：当前为单站点、单管理员，不是多人权限系统

1. 后台按区域组织管理，配置分组可展开/收起。
2. 图片提供上传、预览、取景、比例和保存操作。
3. 媒体条目和栏目设置保存后，前台刷新读取新数据。
4. 取景参数用于显示参考，不会把原图永久裁切成不可恢复的小图。
5. 管理 API 写入需要本站会话；手机与网页共用本站数据。


五、网页后台可自定义内容

A. 站点品牌、文案与显示
- 网站名称、Logo/图标、主标题、强调文字、简介和附加文案。
- 首页各区域开放的 kicker、标题、副标题、补充文字与显示开关。
- 字号、字重、文字显示比例，以及主要图片/图形显示比例。
- 背景与边框基础色、配色、色调、模糊和相关画面效果。
- 页脚、自己的 GitHub 链接与联系邮箱。
- 个人介绍和关于区域文字/图片。
- 不内置站长必须使用的原作者联系方式。

B. 首页卡片与栏目
- 各栏目入口图片和配套展示内容。
- 图片取景、显示比例与布局目标。
- 卡片顺序及可配置的展示大小。
- 相关栏目首页显示开关。
- 首页背景和内容视觉效果。
- 窗口变化时卡片可弹性调整，裁剪参考不等同于原文件裁剪。

C. 欢迎开场
- 启用设置、桌面背景图、手机背景图。
- 两套图像取景和布局参考。
- Logo/水印、标题、副标题、节点文案和顺序/启用状态。
- 图片亮度、模糊、蒙层与水印可见度等效果。
- 加载时长及进入按钮设置。

D. 图片、视频与媒体记忆
- 选择并上传自己的图片/视频。
- 编辑标题、meta 附加信息、正文、日期、排序。
- 分别控制首页、3D 粒子树、故事集的显示状态。
- 根据栏目管理已有内容、预览并保存修改。
- 删除条目只删除数据库引用，不自动清除上传实体与历史备份。

E. 3D 粒子树
- 场景预设：雪景环绕、飘雪、宇宙等源码提供的预设。
- 粒子树密度、雪花/星点密度、亮度。
- 树形生长与照片大小、分布、边框等参数。
- 预设可作为起点再细调；运行性能随设备与参数变化。
- 当前图片打开优化保留全部原有动画。

F. 时间线、文字与关于
- 时间线事件数据。
- 个人介绍、关于区域图片和文案。
- 各栏目已开放的标题、副标题、补充文字和展示选项。
- 静态导航/按钮文案如未提供编辑项，需要自行改源码。

G. 音乐
- 上传自己的音频。
- 管理播放列表及默认播放设置。
- 默认音量、播放顺序、随机/循环等行为。
- 实际自动播放由浏览器权限与用户操作决定。

H. 桌宠
- 选择示例或自有模型，配置显示尺寸和位置。
- 移动、鼠标跟随及互动参数。
- 台词分组、情绪和角色表现。
- 保存/使用配置预设。
- 自己的 DeepSeek Key、模型和允许的官方 API 配置。
- 私密 Key 不进入公开内容 API。

I. 留言与投稿
- 查看留言、回复、图片和状态。
- 隐藏/显示/删除留言。
- 查看投稿正文、图片与联系邮箱。
- 接受/拒绝投稿、删除投稿记录。
- 投稿审核与公开媒体发布是不同操作。

J. 账号与统计
- 内容数量、访问统计及相关状态。
- 网页账号安全/密码恢复流程。
- 邮箱验证码功能需要自己的 Turnstile 和 SMTP 完整配置。
- 更改环境文件里的初始密码不会修改已有数据库密码。

K. 服务器级配置
以下通过 VPS 脚本和环境文件配置，不是在前台公开表单输入：
- DOMAIN：自己的域名；ACME_EMAIL：证书联系邮箱。
- ADMIN_USERNAME：管理员邮箱；ADMIN_PASSWORD：首次创建用密码。
- TURNSTILE_SITE_KEY / SECRET_KEY / ALLOWED_HOSTNAMES。
- SMTP 主机、端口、加密方式、账号、授权码和发信邮箱。
- 验证码密钥、默认端口和演示数据初始化选项。
- 修改配置使用 scripts/reconfigure.sh，先备份再检查。
- 不需要 Cloudflare API Token，也不需要原作者的云服务账号。


六、安卓管理 App 能做什么

1. 首次填写自己的完整 HTTPS 域名，检测本站 API 后保存连接。
2. 随时更换站点，清除旧站点本机令牌，重新登录新站点。
3. 查看媒体数、留言数、待处理投稿、访问量、数据库和存储状态。
4. 相册选择图片/视频，本机压缩、上传，显示上传进度。
5. 编辑媒体标题、meta、正文、日期、排序与三类展示开关。
6. 查看并显示/隐藏/删除留言。
7. 查看投稿，标记接受/拒绝，删除记录。
8. 原生编辑网站名称、首页文案、个人介绍和可增删排序的时间线节点。
9. 在原生账号管理页完成 Cloudflare 验证、邮箱验证码修改或恢复密码；成功后撤销旧会话。
10. 查看版本/构建信息；手动检查自有更新清单并验证 APK 摘要。
11. 连点版本 7 次进入开发诊断，查看状态、延迟、会话和操作摘要。
12. 原生编辑高级排版与取景、首页开场路线、3D参数、MP3上传/播放列表排序、联系链接、桌宠台词/布局/预设，与网站共用数据。
13. 令牌使用系统安全存储并按 origin 隔离；密码不持久保存。
14. 图片压缩保留 EXIF，视频保留声音；压缩不是隐私脱敏。
15. 官方下载为稳定签名正式通用版 memory-archive-admin-v1.6.1.apk，可覆盖相同包名/签名的安全通用版；CI debug工件与正式发行区分。自行重新签名时须妥善保管自己的私钥。


七、使用的技术

前端：
React 19.2.6、TypeScript 5.9.3、Vite 8.0.13。
Three.js 0.185.x、React Three Fiber 9.x、Drei 10.x 实现 WebGL 场景。
Framer Motion 13.x 实现过渡动画。
Tailwind CSS 4.2.1、自定义 CSS 和 Lucide 图标。
react-advanced-cropper 用于网页图片取景。
PixiJS 6.5.10、pixi-live2d-display 0.4.0、Cubism Core 用于桌宠。

后端：
Python 标准库 HTTP 服务与 JSON API。
SQLite 存储内容、设置、管理员、会话、留言、投稿、统计与日志。
PBKDF2-HMAC-SHA256 存储密码摘要；随机会话令牌在后端保存摘要。
App 管理 API 单独使用 30 分钟访问令牌与 30 天刷新令牌。
SMTP、Turnstile 和 DeepSeek 都使用站长自己的配置。

部署：
Docker Compose v2；Node 22 构建前端。
Python 3.12 容器运行 API，Caddy 2 提供 HTTPS 与反向代理。
数据库、上传与证书使用独立卷。
默认 VPS 部署是静态 SPA，不依赖 Next SSR、Cloudflare Workers/D1 或 Drizzle ORM。
GitHub Actions 验证网页、后端、全新容器安装、备份、Flutter 分析/测试/APK 构建。

安卓：
Flutter 3.47.0、Dart 3.13、Material 3。
Riverpod 状态、Dio 网络、安全存储、图片/视频压缩。
JDK 17、Android SDK 36、minSdk 24。
依赖详情见 mobile-admin-app/README.md。


八、数据、隐私和维护边界

1. 网站文件与账号属于自己的 VPS，不共享原作者数据库。
2. 演示图无原作者真人照片，替换为自己的素材即可。
3. 上传目录默认提供公开 URL；隐藏栏目不等于给图片加访问权限。
4. 删除数据库条目不自动删除文件、备份或访客保存的副本。
5. 后端请求体上限 18 MiB；默认没有服务器全量转码或缩略图生成管线。
6. 安卓没有广告、统计上报或崩溃收集 SDK；选定站点、外链素材和自有更新仍会产生网络请求。
7. Cloudflare、邮件、AI、外链媒体等数据流按实际配置参与，详见隐私政策。
8. 网站不是多租户 SaaS、多人管理/RBAC、相册加密库或自动发布投稿系统。
9. 第三方模型授权与署名不能用“完全独立部署”代替；主要程序 MIT 不覆盖全部模型。
10. scripts/backup.sh 保存一致数据库、上传、私密配置和 Git 版本。
11. scripts/update.sh 先备份再更新，失败回退代码与镜像，不主动覆盖当前用户数据。
12. 数据时间点恢复按 docs/SELF_HOSTING.md 手动核对与操作。
13. 不要执行 docker compose down -v；不要把真实 .env、数据库、备份或签名私钥上传 GitHub。

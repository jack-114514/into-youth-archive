# 随手记与图片预览

随手记用于管理员发布短文字记录；访客只阅读已发布的内容。留言操场仍用于访客留言，投稿信箱仍用于投稿。

网页后台进入“网站内容设置 → 随手记”，填写标题、日期与正文，点击“保存草稿”或“发布随手记”。每条记录可编辑、改回草稿、归档，归档内容可编辑后重新发布。记录按日期倒序展示，同日按创建顺序倒序。页面标题与介绍仍使用“保存全部设置”；具体记录使用编辑器自己的保存按钮。

文字按纯文本显示并保留换行，不执行 HTML 或脚本。标题最多 100 字，正文最多 12000 字。记录位于 SQLite 的独立 notes 表；访问 /api/admin/notes 及写入操作需要现有管理员会话。/api/notes 只返回已发布记录。

图片列表优先使用 thumbnail_url。缺少预览的本站图片会生成最长边 720px、保持原比例的 WebP；已有管理员取景图优先保留，原图不覆盖、不删除。网页与安卓管理员新增或更换图片并保存时会自动补充预览，启动时补齐历史缺失项。网页选择图片后可以直接保存，手动取景按钮仅在需要调整画面时使用。更换原图时会重新生成匹配的预览；只修改文字时保留原预览。手机 MPO 多帧 JPEG 使用首帧生成静态预览；动画 GIF 和不支持的素材保持原有显示。

自动生成预览需要 Pillow。Ubuntu 可安装发行版包 python3-pil。未安装时保持原图显示，不影响已有缩略图或网站启动。此模块不下载任意外部图片，也不读取上传目录之外的文件。

校园碎片只挂载当前栏目，其他栏目不再作为隐藏 DOM 同时渲染。原有背景与桌宠设置保留。

代码回滚可恢复旧静态与 app.py；保留当前数据库、上传内容与已新增随手记。旧版本会忽略新增 notes 表。灾难恢复数据库前必须另存上线后写入，避免覆盖新内容。

安卓1.8.0：网站内容设置 → 随手记 → 随手记内容，使用同样的草稿、发布、编辑和归档操作。栏目设置保留标题及介绍编辑。原生接口为/api/v1/admin-app/notes，使用安卓会话，网页会话不能访问。

# 墨灵助手

墨灵是现有桌宠助手中的图片角色，后台“AI 桌宠设置 → 助手形象”可选择。聊天接口、访客身份、休息唤醒、后台参数和角色预设复用现有实现。

## 素材

网站所有者提供的主形象、头像、12姿态修正版及设定图保存在 `public/assets/desktop-pet/moling/`。PNG 原始字节、透明通道和分辨率保留；`SOURCE.json` 记录 SHA256。12姿态图为 1448×1086 的4列3行网格，网页用 CSS 选取对应区域，不切割或重绘原图。

姿态顺序：漂浮、眨眼、张望、打盹、挥手、跳跃、转身、青玉光点、思考、害羞、惊讶、完成。它们是独立姿态图片，浮动、挥手摆动和跳跃位移由网页动画补充，不属于 Live2D 模型或连续逐帧动画。

当前显示使用 `rig-v2.png` 六部件透明图集（3列2行、1536×1024）：身体、左右手、顶部墨卷、底部墨尾和青玉。图集通过内置 image_gen 从主形象修整，原始PNG及旧姿态图完整保留。`RIG-SOURCE.json` 记录参考哈希、生成方式、完整提示词和新素材哈希。网页按测量边界选取部件，PNG字节不经二次抠图或重绘。

表情采用同一张黑色面板上的SVG眼睛、脸红和嘴型，连续变形，不叠加整张表情图片。12动作仍沿用原控制器时序；动作映射到分部件的手势、视线、转向、升降、墨尾和青玉光点。临界阻尼弹簧保留位移和速度，快速切换从当前运动状态衔接；身体和部件用短CSS插值补充帧间运动。动作与眼神跟随保留余下帧时间，遵守后台帧率上限；减少动态效果关闭漂浮、装饰和插值。聊天圆形头像也使用新版图集与固定笑眼。

## 交互

- 单击开关聊天，双击休息，键盘 Enter/空格打开聊天。
- 鼠标仅驱动面板内的眼睛视线，身体位置不会跟随或随机游走；按住角色仍可主动拖动。横向视线最大6个SVG单位、纵向3.5，距离越近偏移越小。聊天时继续眼神互动；拖动、离开页面、休息、隐藏、关闭开关和减少动态效果会让视线回中。后台原“鼠标跟随”开关对墨灵显示为“眼睛跟随鼠标”。
- 待机定时眨眼和张望，随机动作轮换张望、跳跃、转身、青玉光点和打盹。
- 重复点击不重新启动正在播放的挥手；随机动作不覆盖正在执行的动作。
- AI 等待状态保持思考；回复切换相应表情，动作完成后恢复待机；失败显示惊讶后恢复，取消清除思考状态。
- 减少动态效果偏好关闭 CSS 位移动画和指针跟随。沿用当前桌面限定显示策略。
- 保留12个动作预览按钮，另有14个独立表情按钮：平静、开心、害羞、思考、惊讶、难过、好奇、兴奋、困惑、困倦、生气、喜欢、得意、眨单眼。AI可返回同名英文情绪，面部独立于身体手势；表情使用连续参数变形，预览不调用 AI。

`MolingRenderer.tsx` 负责图片载入、姿态和显示；`moling.ts` 负责动作时序，`moling-face.ts` 负责独立面部表情时序、形状与视线计算，`moling-rig.ts` 负责部件坐标、连续表情参数和弹簧运动；`DesktopPet.tsx` 默认使用墨灵渲染器，管理员可切换自定义图片或Live2D；旧内置角色在服务端读取配置与预设时迁移为墨灵。

## 验证

新增 Node 测试覆盖12姿态、动作恢复、重复触发、等待回复、休息重置、眼神范围与原始素材哈希。后端测试覆盖墨灵配置、公共读取、帧率、语态及预设持久化。浏览器验收使用独立临时数据库，不向真实 AI 服务发送测试请求。

过渡修正另验证12姿态身体锚点和高度一致、浏览器实际出现部分透明的中间帧、漂浮动画时间持续递增、跳跃连续采样、快速打断后只剩一个可见图层、动作结束恢复待机及减少动态效果。

部署时仅修改角色与名称为“墨灵”，其他已保存配置、API Key、角色预设和网站内容保持原值。发布前保存独立静态、后端和 SQLite 回滚点；回滚恢复桌宠文件及此前角色选择，不用旧数据库覆盖发布后新增的用户数据。

## 表情与边缘第二次修正验证

13项Node测试包括原素材保留、6部件新素材哈希与RGBA、全部动作有限参数、临界弹簧打断与收敛、不同帧率一致性及跳跃起落连续性。图集逐格检查有效透明像素及主体边界，网页逐帧检查固定部件和面部节点、12动作、眼睛路径变化、害羞脸红/惊讶嘴型、帧间隔、跳跃、快速打断、恢复待机、减少动态效果，并在白色、深色与青玉背景保存抠图截图。AI使用临时接口模拟等待与完成，不向真实服务发送测试请求。

本轮仅发布新静态资源；不修改后端、桌宠设置、密钥、预设或用户数据，服务器独立回滚点仍备份静态与一致性SQLite数据库。此前“220ms整图过渡”已由同一角色分部件连续运动替代。

## 眼神与输入框修正

移除鼠标驱动身体位移的实现；待机轻微漂浮与主动点击动作保留。14种脸部状态分别调整左右眼开合、眉形、嘴型、脸红、泪滴、心形眼与亮点。表情寿命独立于手势，重复挥手被忽略时仍能更新回复表情。视线按临界阻尼平滑衔接，面部图形限制在黑色面板内。

聊天输入框取消绿色矩形聚焦轮廓，保留外层圆角玻璃输入栏的柔和聚焦提示及按钮的键盘焦点样式。浏览器同时检查鼠标与键盘输入时的计算样式。发布包含静态文件与情绪白名单后端更新，不改变已保存设置、密钥、预设和用户数据。

## 拖拽专属互动

新增3组不在AI情绪白名单或普通预览按钮中的拖拽专属表情和动作：被拎起·慌张（睁大眼、张嘴、双手抬起、身体上提），乘风·开心（笑眼、脸红、张开双臂、身体顺移动方向倾斜、墨尾与顶部墨卷反向摆动），晃晕·委屈（螺旋眼、委屈嘴型、泪滴、身体摇摆、双手晃动）。鼠标在可拖动角色上按下并移动超过5px才启动；最初650ms为被拎起，随后缓慢拖动进入乘风，快速移动或来回改变方向触发短暂晕眩。

松手、指针取消、失去捕获、窗口失焦、页面隐藏和角色暂停会退出拖拽。表情和部件通过弹簧衔接至原状态，正在等待的AI思考状态可恢复。拖拽结束不打开聊天，不触发双击休息；普通悬停、点击、键盘或AI响应不会触发这3组互动。减少动态效果保留静态拖拽表情和手势，关闭摇晃。`moling-drag.ts`独立计算触发阈值、速度、方向、持续时间与反应参数。

点击聊天月亮或双击休息时，墨灵先播放约1.3秒挥手再见，最后250ms淡出，再显示唤醒按钮；重复触发不会叠加退出定时器。减少动态效果使用约400ms静态告别。页面暂停时完成休息，卸载时清除定时器；唤醒不会被旧退出任务再次隐藏。

管理员仍可选择自定义图片（PNG/JPEG/WebP/GIF/AVIF/SVG）或有授权的 Cubism 3/4 Live2D。网页后台与通用App填写本站资源路径或HTTPS地址；Live2D使用.model3.json入口且保持贴图、动作等相对路径完整。默认安装不加载Live2D运行库。自定义角色可以分别设置语态、人设与名称。

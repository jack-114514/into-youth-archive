Independent self-hosted distribution with the latest animated website, neutral demo illustrations, and a native Android admin app.

- First-run VPS installation creates your own administrator and persistent data.
- Configure your own domain, Cloudflare Turnstile, SMTP, and site content.
- Android asks for your HTTPS domain on first launch; switching sites clears the active session.
- No author's uploads, database, personal domain, cloud credentials or signing key are included.
- The attached preview APK is debug-signed for testing. Build and sign a release APK with your own key for long-term use. Preview signing keys may change between CI builds.
- The program is MIT; bundled Live2D demo models and Cubism Core have separate terms in public/THIRD_PARTY_NOTICES.txt.
